# Your-Skin
A Mod for Luanti to change your skin into a custom skin on your PC
You can make Custom Skins or Download Skins on the Site https://www.minecraftskins.com/
You only must covert these Skins on the Site https://godly.github.io/minetest-skin-converter/
And you have you own skin in Luanti,if you put the png in the file ~/.minetest/mods/your-skin-v2/textures/

And you can have animated Skins!
